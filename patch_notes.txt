
TL;DR:
- Over ten new focus trees have been added, including for countries in the Mirkwood, the Vales of Anduin, Misty Mountains and Rhûn areas
- Several new unit model, GUI and map changes
- Improvements to existing focus trees for Rohan and Lothlorien
- New mechanics/systems for artifacts, fellowship and Mordor's menace
- Various bugfixes, balance changes and QoL improvements


MIRKWOOD
- Major map changes in the Mirkwood area
- Dol Guldur and Spiders of the Mirkwood now start as released, playable countries
- Added new, custom focus trees and other content for Mirkwood, Dol Guldur and the Great Spiders
- Added several new unit models for the Great Spiders (Can be turned off in the custom game settings)
- Added new custom tech tree for the Great Spiders

VALES OF ANDUIN
- Major map changes in the Vales area
- The Vales of Anduin have been split into three separate countries
- Added custom focus tree and other content for each Vales country, as well as two shared trees

MISTY MOUNTAINS
- Major map changes in the Misty Mountains area
- Goblin Town has been added as a new playable country, including a custom focus tree and other content
- Revised, improved and integrated Gundabad's focus tree from the Bonus Trees submod
- Revised, improved and integrated Rhudaur's focus tree from the Bonus Trees submod
- Major map changes to the Mines of Moria
- Added new unit model for dwarves

RHUN
- Major map changes in the Rhûn area and surroundings
- Revised, improved and integrated Rhûn's focus tree from the Expanded submod
- Logath joins the fray as a playable country
- Added Avari Tribes as a releasable tag

MORDOR
- Added a new "Menace" mechanic to Mordor
- Added and changed several focuses to Mordor's focus tree

LOTHLORIEN
- Added new inlay to Lothlorien's focus tree
- Revised Lothlorien's focus tree layout and connections to be less spaghetti
- Revised Galadriel's Mirror mechanic
- Various bugfixes
- The Twin Hearts of Lorien focus has been nerfed significantly

ROHAN
- Added new inlay to Rohan's focus tree
- Theodred will only die if he is a Marshal
- The Landsmeet focus now allows you to re-appoint marshals of regions already changed
- Political power gain has been rebalanced to not rely on Fulcanstan
- Various other bugfixes and balance adjustments
- Minor map changes to Westmarch area

OTHER CONTENT
- Added a new 'artifacts' system to manage various precious items
- Reworked the way food consumption works and the penalties it applies
- Added several new achievements
- The fellowship system has been moved out of the decisions screen into it's own window
- Several changes to the way fellowship detection works and the information displayed during an interception
- Several new terrain types have been added to reflect underground areas in Moria and Goblin Town

VISUAL
- Removed 3D models of trains
- Disabled legacy unit models
- All ship types have received new unit models
- The topbar GUI has been reworked
- Several new ambient objects have been added to the map, including shading improvements
- Several focus, idea and event images have been added or changed
- All unit models have been shrunk by 25% to accomodate the new, smaller provinces

QOL/BALANCE/BUGFIX
- Improved ownership-links of impassable states
- Removed PP-gain penalties on higher difficulty settings
- PP gain of centralization laws have been slightly increased
- Reduced manpower gain from mercenary laws, increased manpower gain from levies
- Fixed naval invasion techs
- The Ithilien crisis has been rebalanced to be less Mordor-favoured
- Many more undocumented changes and improvements
- Chariots have been rebalanced to grant more hardness, but less armor and attack, as well as costlier modules
- mastery gain for all doctrines has been increased
- Historical Rivendell forms the Rivendell Initiative later
