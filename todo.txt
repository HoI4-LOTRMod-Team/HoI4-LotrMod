Misty Mountains shader notes/status:

The only thing in pdxmesh.shader required to show the country borders is to have the "PDX_GRADIENT_BORDERS" define active.
I can either achieve this by manually removing it (although this may/will lead to problems elsewhere)
or simply use a shader that has the dfine already. Like, simply using "PdxMeshStandardSnow" in the model may be enough

However, one more thing needs to be done: When the camera zooms out, it should move the model down underneath the ground or make it transparent or something
This will require more control.

Question: Is it possible to define a new shader like this?

Effect PdxMeshStandardSnow
{
	VertexShader = "VertexPdxMeshStandard"
	PixelShader = "PixelPdxMeshStandard"
	Defines = { "PDX_GRADIENT_BORDERS" }
}

and then change the vertex shader to move the model away at a certain distance?

The answer is YES!

I've added a custom shader (hardly modified at all atm). It's called "PdxMeshStandardLotr". Simply use that when exporting the model under custom properties!
